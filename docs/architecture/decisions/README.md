# Architecture decisions

The [canonical architecture](../RAG_FACTORY_DESIGN.md) describes current accepted boundaries. The [deprecation register](../DEPRECATIONS.md) records assumptions that must **not** guide new implementation.

## Decision status conventions

- **Accepted:** governs new work on `dev`.
- **Proposed:** under discussion; no code requirement yet.
- **Superseded:** retained for historical context only.

New ADRs should identify the decision, rationale, alternatives, impact, and which prior decision (if any) they supersede. Update the canonical design and deprecation register whenever a decision changes.

The original processor-centric document is [historical/superseded](../ARCHITECTURAL_PRINCIPLES_PROCESS_CENTRIC.md), not a competing source of truth.
